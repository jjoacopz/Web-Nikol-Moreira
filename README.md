# Web-Nikol-Moreira

Sitio web de dirección creativa y estilismo de Nikol Moreira.

## Descripción

Esta web funciona como un portafolio digital que muestra los proyectos de dirección creativa y estilismo, con énfasis en la presentación visual de producciones audiovisuales y editoriales.

## Estructura del Proyecto

```
.
├── index.html           # Página principal
├── styles/
│   └── main.css        # Estilos principales
├── js/
│   └── main.js         # Lógica de la aplicación
├── public/
│   └── images/
│       └── segunda-piel/  # Imágenes del territorio compartido
└── package.json        # Configuración del proyecto
```

## Territorios Compartidos

### Segunda Piel
Archivo de looks construidos a partir de la observación del trabajo rural. Los estilismos son trasladados a una modelo con el objetivo de preservar y reinterpretar estos elementos desde un lenguaje editorial.

## Desarrollo

Para ejecutar el servidor local:

```bash
npm run dev
```

El sitio estará disponible en `http://localhost:3000`

## Características

- Galería de imágenes responsiva
- Lightbox para visualización de imágenes en detalle
- Navegación suave
- Diseño minimalista y elegante
- Optimizado para móvil
